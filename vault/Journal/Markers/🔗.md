This marker signifies a link to external material. I use it primarily for projects to collect links to reference material (presentations, websites, and so on).

This marker has an `export-links` property, set to `true`. That makes any external links show up in the `links` query for the HTTP server. Try:

```zsh
curl -s http://localhost:7767/curators/demo/queries/links\?document\=Markdown%20Curator | jq
```

It should output something like:

```json
{
  "items": [
    {
      "name": "Jetty HTTP Server documentation",
      "url": "https://jetty.org/docs/jetty/12.1/programming-guide/server/http.html"
    },
    {
      "name": "Alfred Markdown Curator workflow",
      "url": "https://github.com/voostindie/alfred-markdown-curator"
    }
  ]
}
```

...provided that the server is enabled (`-s` or `--server`) and that it's running on its default port of 7767.

Do you have other markers that typically hold links to external content and that you want to include in the output of the `links` query? All you need to do is set the `export-links` property.

By the way: the `links` query also includes any links in the *Links* section of each document. That name can be overridden, but that needs to be done in the Java code of the [[Markdown Curator Demo]].

On my Mac the keyboard snippet `,ml` expands to this marker.
