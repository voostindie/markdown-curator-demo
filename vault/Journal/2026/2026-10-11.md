## 🏃 Activities

- A recent addition to the [[Markdown Curator]] is an optional embedded HTTP Server. It offers various nice features, like this one:
	- [[🔗]] [Jetty HTTP Server documentation](https://jetty.org/docs/jetty/12.1/programming-guide/server/http.html)
	- What's so nice here, you say? Well, the [[🔗]] marker is configured with the setting `export-links`, which makes it contribute any external links to the `links` query available through the HTTP server. See the [[🔗|marker itself]] for more information.
	- This in turn plays nice with the [Alfred Markdown Curator workflow](https://github.com/voostindie/alfred-markdown-curator-workflow), also just released. Instant link browsing. [[🔗]]
	- The background here: I suck at maintaining bookmarks in my browser(s). I sporadically save links, hardly ever organize them, and always forget to clean them up. In my notes however, it's much easier: I just drop a link in my daily journal under a topic with a marker, and I have instant contextual bookmarks.
